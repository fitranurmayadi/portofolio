# Fitra Nurmayadi — Portofolio Embedded Systems & IoT

🌐 **Live Site**: [https://fitranurmayadi.github.io/portofolio](https://fitranurmayadi.github.io/portofolio)

Portofolio proyek-proyek Embedded Systems, IoT, Robotics, dan Life Science oleh **Fitra Nurmayadi**.

## ✨ Fitur

- 🔍 Pencarian & filter berdasarkan kategori (Embedded Systems, IoT, Robotics, Life Science)
- 🖼️ Galeri gambar carousel untuk setiap proyek
- 🌙 Mode gelap & terang
- 📱 Responsive design (desktop, tablet, mobile)
- ⚡ Static site — tanpa backend, langsung dari GitHub Pages

## 📂 Struktur Proyek

```
├── index.html          # Halaman utama
├── style.css           # Styling (dark/light mode, glassmorphism)
├── script.js           # Logic (fetch, filter, search, carousel, modal)
├── projects.json       # Data 18 proyek dalam format JSON
├── assets/images/      # 80 gambar proyek
├── .nojekyll           # Bypass Jekyll di GitHub Pages
└── README.md           # File ini
```

## 🚀 Deploy ke GitHub Pages

1. Buat repository baru di GitHub (misal: `portofolio`)
2. Push semua file ke branch `main`
3. Buka **Settings → Pages → Source** → pilih `main` branch, folder `/ (root)`
4. Tunggu beberapa menit, situs akan live di URL di atas

## 🛠️ Tech Stack

- HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- Google Fonts (Outfit, Space Grotesk)
- Font Awesome 6 (icons)
- Dimigrasikan dari WordPress + GitHub scraping
